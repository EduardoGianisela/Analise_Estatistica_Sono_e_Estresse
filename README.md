# Análise Estatística: Saúde do Sono e Estresse (Care Plus)

Este projeto foi desenvolvido como parte de uma iniciativa de **Saúde 4.0**, utilizando técnicas de análise exploratória de dados para identificar padrões de comportamento e saúde.

## Principais Descobertas
* **Correlação Crítica:** Identifiquei uma **forte relação inversa ($r \approx -0,83$)** entre a duração do sono e o nível de estresse.
* **Distribuição Multimodal:** A análise de idade revelou múltiplos grupos etários com comportamentos de saúde distintos.
* **Biomarcadores:** A Frequência Cardíaca de Repouso foi identificada como um indicador de regime estacionário para saúde preditiva.

## Tecnologias Utilizadas
* **Python** (Pandas, Numpy)
* **Visualização de Dados** (Seaborn, Matplotlib)
* **Estatística Descritiva e Inferencial**
